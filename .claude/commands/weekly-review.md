# Write the Monday policy review

Run `npm run policy -- weekly-review`. Use `--json` for structured results.
Resolve names from the register before a write. If ambiguous, list candidates and stop for a selection. Never invent records or evidence.

The command reads the review calendar, acknowledgements, exceptions and attention list together. Write named owners, overdue days, the next evidence needed and any missing effective versions. Never infer receipt from an assignment.

Present the result in plain words, citing the record reference. Do not email, distribute policies or connect an external service.
