# Record an independently approved policy as effective

Run `npm run policy -- make-effective <revision> --actor=<operator>`. Use `--json` for structured results.
Resolve names from the register before a write. If ambiguous, list candidates and stop for a selection. Never invent records or evidence.

Read the policy and proposed version first. Confirm the operator has authorised this internal status change. The database requires an independent approval and consultation evidence for a safety policy. This records effectiveness locally; it distributes nothing. Do not treat approval text as proof of legal compliance.

Present the result in plain words, citing the record reference. Do not email, distribute policies or connect an external service.
