# Add a view
Inspect the schema and current views.json. Write a SELECT query using existing records and add a named section to views.json. Use an invoker-rights view if adding a database view. Render with npm run view and inspect the result. Never add forms, buttons that change records, a server or external sharing. Escape record values using the shared renderer. Explain which question the view answers.
