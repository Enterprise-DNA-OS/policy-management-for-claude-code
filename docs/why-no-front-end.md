# Ask the register, keep the evidence

The weekly job is to find overdue reviews, missing acknowledgements and unapproved versions. A database plus a coding agent can read those records, prepare a brief and record an authorised action. No browser application is required for a policy coordinator to do that work.

A screen adds self-service employee access, mobile browsing, authenticated acknowledgements, rich document editing and notification controls. This base does not offer those experiences. It writes read-only HTML reports and policy packs for local review or printing. It has no offline synchronisation, drag-and-drop editor or electronic signature service. Enterprise DNA can build the screen and connections a business needs as part of its custom scope.

The agent is the door, not the database. CLAUDE.md and AGENTS.md support Claude Code, Codex, OpenCode and Cursor. Keep private records in the approved environment and review the coding agent's data-handling settings before using business data.
