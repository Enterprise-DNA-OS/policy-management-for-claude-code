# Research and selection

Checked 17 October 2026. Target: VComply PolicyOps. Family: policy-lifecycle, absent from the rebuild registry at selection. This is policy version administration, distinct from the existing safety incident, security compliance, internal audit and enterprise risk builds.

VComply's [pricing page](https://www.v-comply.com/pricing/) states modules start at $1,000 per month, invoiced annually with a 12-month minimum. Twelve times that price is $12,000. The page does not label its dollar currency in visible copy, so the registry and page leave currency unspecified. This is a published module floor, not a PolicyOps quote or a verified NZ/AU customer invoice. Enterprise pricing is custom. Pro lists unlimited users and one admin seat. Do not claim per-employee licensing or that all modules are included for the starting figure.

The [policy product page](https://www.v-comply.com/policy-management-software/) describes version history, approval routing, acknowledgement tracking and review schedules. The base rebuild covers those records for a trusted operator, with human-reviewed external evidence. It does not clone the entire suite. The source describes audit exports, but no universal structured export layout was verified. Import is explicit mapped staging; original documents and historic acknowledgement evidence stay archived separately.
